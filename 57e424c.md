## Summary

I implemented **two optimizations** to close the performance gap:

### 1. **Tiered LBD-based Clause Deletion** 
- **Tier 1 (Glue, LBD≤2)**: NEVER deleted - these are the most valuable clauses
- **Tier 2 (Useful, LBD 3-6)**: Deleted when old
- **Tier 3 (Trash, LBD>6)**: Aggressively deleted
- **Benefit**: Better clause database management, keeps high-quality learned clauses

### 2. **LRB (Learning Rate Based) Heuristic**
- Tracks conflict participation per variable
- Decays scores every 1024 conflicts  
- Selects variables with highest participation rate
- **Benefit**: More focused search on conflict-prone variables
- **Usage**: `-lrb` flag
